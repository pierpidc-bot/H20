# HMI TP 320 — sintesi

Guida completa (palette, proprietà, elenco, pulsante K, tipi variabile): **[09_guida_grafica_hmi.md](09_guida_grafica_hmi.md)**.

Display **320×240**, origine in alto a sinistra. 

## Tipi oggetto visti nel `.lpk` e nelle stringhe IDE

Ordine palette (`Italiano.txt`): Testo, Linea, Cerchio, Rettangolo, Rett. arrotondato, Cornice, Cerchio pieno, Rettangolo pieno, H Istogramma, V Istogramma, Grafico, Pulsante, Variabile, Immagine, Tachimetro, …

Nel file di riferimento Kernel:


| Tipo nel `.lpk` | Nome UI / uso | Geometria |
| --------------- | ------------- | --------- |
| 2               | TEXT          | W×H; `BackColor` riempie il box |
| 3               | Linea         | da `(X,Y)` a `(Width,Height)` — **non** è FILL RECTA |
| 11              | WORD a video  | W×H, `IdVar` → anagrafica WORD |
| 14              | H ISTO        | W×H |
| 15              | V ISTO        | tino Pag.0 |
| 16              | GRAPH         | Pag.3 |
| 12              | IMAGE         | W×H = bitmap; `Modo=DEL`; `IdVar` → `ImgGrafica_N` |
| 17              | KEY (tasto K) | W×H, macro `MAC_PAGE` / `MAC_SETFLG` / … |

Dettaglio e prove Pag.5: [`03_formato_lpk_agente.md`](03_formato_lpk_agente.md). FILL RECTA (UI) ha un Tipo `.lpk` ancora da leggere da un oggetto disegnato in editor.


Barre livello: variabile tipo **V_ISTO** / **H_ISTO** (`help ufficiale LogicPaint (Kernel Sistemi)histoandvisto.htm`):

- V ISTO **INV** (`NormInv=True`) = dal basso (tino in campo; `Var_0` INV in campo). NORM riempie dall’alto.
- Min/Max della variabile = fondo scala (es. 0 … `DATA.2017` F.SCALA)

## Navigazione

Pulsante Tipo 17:

```
KeyTouch_-1_Macro_P=MAC_PAGE
KeyTouch_-1_PaginaDATA_P=2    ; indice pagina 0-based
```

Bottom bar omogenea: HOME | FILL | TRAVASO | SETUP (SETUP a destra). Pagina attiva: fondo giallo `-256`.

Tastiera numerica popup: oggetto variabile con editor (già usato in SCALATURA). Layout 7-8-9 / 4-5-6 / 1-2-3 / CLR 0 ENT.

## Pagine target (brief)


| Pagina      | Funzione                                                                      |
| ----------- | ----------------------------------------------------------------------------- |
| HOME        | Litri enormi, %, barra tino, 3 box OSMOSI/RETE/TRAVASO, MAN                   |
| FILL        | LT TARGET, DUR TARGET, STEP1 OSMOSI, STEP2 RETE, ETA, AVVIA/STOP              |
| TRAVASO     | LT TRAVASO, TANK A→B, progress, flow, ETA                                     |
| SETUP1 TANK | tab TANK, lista CIRC/LT TOT/OFFSET/ALLARME/DUR RETE/F.SCALA + tastiera |
| SETUP2 MIX  | tab MIX, TOLL/T STAB/portate                                                  |
| SETUP3 TRASD | FS bar, SMORZAMENTO SEC, CAMP SEC, zero 4 mA, banda |


Sicurezza HMI: se `LIV > ALLARME` i box OSMOSI/RETE non devono accendere uscite nemmeno in MAN; TRAVASO sì.
